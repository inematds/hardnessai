🏰 Sand Castle setup

Use o Sand Castle plugando Docker/Podman (local) ou Vercel sandboxes (remoto) para rodar os agentes isolados.

📊 Opções de sandbox

  • Local: Docker ou Podman.
  • Remoto: Vercel sandboxes.
  • Combinável com GitHub Actions.

📥 Puxar commits de volta

Com sandbox remoto + GitHub Actions, você puxa os commits de volta ao workspace local quando o trabalho está pronto.

💡 Dica prática

Deixe o agente trabalhar na nuvem e traga só os commits prontos. Sua máquina fica livre o tempo todo.
